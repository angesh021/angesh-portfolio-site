# Projects Assets

This directory contains assets for each of the projects displayed in the portfolio. Each project has its own dedicated folder for images and videos.

## Structure

- \`project-admin-dashboard/\`: Assets for the Admin Dashboard Platform
- \`project-enterprise-nac/\`: Assets for the Enterprise NAC Lab
- \`project-aura-ttt/\`: Assets for the Aura Tic-Tac-Toe App
- \`project-hse-vax/\`: Assets for the HSE Vaccination APP
- \`project-network-lab/\`: Assets for the Enterprise Network Lab Design
- `project-home-soc-lab/`: Assets for the Home SOC Lab
